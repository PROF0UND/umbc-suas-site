The telemetry radio is what allows communication between the UAV and the Ground Control Station (GCS). Skypiea is equipped with a [100mW 915Hz Holybro Sik Telemetry Radio](https://holybro.com/products/sik-telemetry-radio-v3?variant=41562952302781). This radio allows plug-and-play usage where either radio can be on the UAV and connected to GCS laptop. It is also fairly inexpensive
